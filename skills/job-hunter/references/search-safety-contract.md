# Search Safety Contract

Job-board search runs use one source and one country per invocation, bounded query batches, exact-URL CDP preflight, browser keepalives, resumable checkpoints, and hard stops for verification or CAPTCHA walls.

A report may be called final only when every requested source run completed, stale postings were excluded, and every application candidate has salary provenance. Missing sources or evidence produce a partial report with explicit gaps.

Review evidence semantically through structured artifacts; do not treat free-form substring matching as proof.
